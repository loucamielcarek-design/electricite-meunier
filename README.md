# Électricité Meunier — site vitrine

## Fichiers
- `index.html` : structure complète du site
- `style.css` : design responsive blanc / bleu marine
- `script.js` : menu mobile, année automatique et formulaire de devis

## À personnaliser avant publication
1. Dans `script.js`, remplacez `EMAIL_ICI` par l'adresse Gmail professionnelle exacte.
2. Remplacez les photos de démonstration par les vraies photos de l'entreprise/chantiers.
3. Remplacez les blocs « Client à compléter » par de vrais avis avec l'accord des clients.
4. Vérifiez le numéro de téléphone avant mise en ligne.

## Publication
Le site est statique et peut être hébergé sur GitHub Pages, Netlify, Vercel, OVH, etc.
